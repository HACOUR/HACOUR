## 🏠 Homelab

- Proxmox cluster
- FortiGate + MikroTik + UniFi with segmented VLANs
- Self-hosted: Jellyfin, n8n, Pi-hole, CrowdSec, Actual Budget, automatic disc ripping
- Monitoring with Grafana / Prometheus (rebuild in progress)
